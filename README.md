One line, at most 200 characters, about a small good thing that happened
today — a warm bun, a refused coin, and a little luck carried home.

Entry for the [Make the Judge Smile](https://make.fun/bounty/u-gentle-badger-68-make-the-judge-smile-9228676d)
bounty on [make.fun](https://make.fun).

## Run

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output` when unset).
